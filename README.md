# Reelbook

Movie ticket booking app (React + Vite). No backend: all data lives in localStorage.

## Run
    npm install
    npm run dev

## Logins
- Admin: admin@reelbook.com / admin123
- Demo user: user@reelbook.com / user123
- Users: register from the Sign in page

## Reset data
Clear localStorage keys starting with `rb_` in your browser dev tools.
